    • parseListUnsubscribe(
          listUnsubscribe: string | undefined,
          listUnsubscribePost?: string,
      ): ParsedUnsubscribe | undefined

      Parse RFC 2369 List-Unsubscribe and RFC 8058 List-Unsubscribe-Post header values into a structured unsubscribe target.

      The List-Unsubscribe value is a comma-separated list of angle-bracketed URIs offering alternative mechanisms for the same unsubscribe, e.g. <https://host/unsub?id=1>, <mailto:unsub@host>. The first mailto: URI is captured as mailto. The first HTTPS URI that passes outbound-safety validation (see isSafeOutboundUrl) is captured as either oneClickUrl — when the List-Unsubscribe-Post value contains List-Unsubscribe=One-Click (RFC 8058), so it is safe to POST automatically — or otherwise as landingPageUrl, an RFC 2369 page the user opens to complete the unsubscribe.

      The header value is sender-controlled, so an HTTPS URI that targets an internal, loopback, link-local, or otherwise non-routable host (an SSRF vector) is rejected here and never captured; scanning continues so a safe HTTPS alternative in the same header is still used. Additional same-kind URIs are dropped and non-HTTPS URLs (e.g. http://) are ignored. Returns undefined when no usable target can be extracted.
